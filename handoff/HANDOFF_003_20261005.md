## 1. 任务目标
- 最终目标：基于 FastAPI + 现代深色磨砂玻璃 Web UI 的本地作者画师作品同步更新、自动查缺与归档管理工具（F95zone 论坛爬取、资源解密下载、智能 Diff、自动 7z 解压归档至本地素材库）。
- 验收条件（可检验）：
  1. 所有改动或新增功能必须在独立分支完成，提交前运行自动化测试，经用户审核并在 GitHub 确认点头后才能合入 `main`；
  2. 正式发布包必须严格遵守 Release 规范，绝不包含 `test_*.py` 与 `handoff/` 等非运行时文件；
  3. 专楼发布项完整展示选项名称，杜绝同月份项目截断与吞并折叠；
  4. 支持内置下载 HTTP Range 断点续传、暂停、恢复与取消，支持 IDM 进程直接调起（防盗链消除）；
  5. 下载目录全面支持自定义相对或绝对路径，支持旧路径自动纠偏自愈。
- 约束（技术栈、时间、禁区等）：
  1. 严禁直接向 `main` 分支 push 或 merge；
  2. 严禁在代码或仓库中硬编码用户个人路径（如 Windows 用户名、私人盘符等）；
  3. 绝不泄露任何真实 Cookie、Token（必须使用 `.gitignore` 保护并严格脱敏）。
